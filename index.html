Integrasi Real-Time Google Spreadsheet

Hubungkan aplikasi ini ke Google Sheets menggunakan Google Apps Script (Gratis & Tanpa Server Tambahan).

Jam Batas Terlambat: 07:15 WIB

Panduan Setup Google Spreadsheet (Untuk Tim IT MI ITB):

  1. Buka Google Sheets baru, beri nama misalnya Absensi MI ITB 2026.
  2. Buat 2 tab sheet di bagian bawah dengan nama persis: Absensi_Siswa dan Absensi_Guru.
  3. Klik menu Ekstensi (Extensions) > Apps Script.
  4. Hapus semua kode yang ada, lalu salin dan tempel kode di bawah ini:
function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var data = JSON.parse(e.postData.contents);
  
  // Pilih sheet berdasarkan kategori (SISWA atau GURU)
  var sheetName = (data.role === 'GURU') ? 'Absensi_Guru' : 'Absensi_Siswa';
  var sheet = ss.getSheetByName(sheetName);
  
  // Buat sheet otomatis jika belum ada
  if (!sheet) {
    sheet = ss.insertSheet(sheetName);
    sheet.appendRow(['Tanggal', 'Waktu', 'ID Kartu', 'Nama Lengkap', 'Kelas/Jabatan', 'Jenis Absen', 'Status Kehadiran']);
  }
  
  // Tambahkan baris data absensi baru
  sheet.appendRow([
    data.date,
    data.time,
    data.id,
    data.name,
    data.info,
    data.type,
    data.status
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({ 'result': 'success' }))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. Klik tombol Terapkan (Deploy) > Deployment baru (New deployment).

  4. Klik Terapkan, salin URL Aplikasi Web yang muncul, dan tempel pada kolom di atas.
